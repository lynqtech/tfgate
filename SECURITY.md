# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately with GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.

## Scope

tfgate approves Tofu plans and changes Flux and tofu-controller resources in live clusters. Treat kubeconfig files, RBAC grants and plan contents as sensitive when you report an issue or share logs.
